# 黑米姐姐

> 面向社区家庭消费者与社区联营门店的本地生活零售平台，以“社区联营 + 线上下单 + 线下提货”为核心模式，让用户就近买到可信商品，也帮助门店拓客与提升复购。

## 项目简介

“黑米姐姐”围绕社区一刻钟生活圈建设线上线下一体化服务。消费者通过小程序查找附近门店、浏览商品并在线下单，到店自提；社区联营门店负责商品展示、订单履约与社区运营，平台提供商品、内容、订单和运营支持。

项目当前优先建设消费者端，后续逐步完善门店端和平台管理端。

## 产品定位

- **目标用户：** 社区家庭消费者、社区联营门店店主
- **核心场景：** 附近找店、线上选购、到店自提、社区拼团
- **核心价值：** 用户购买方便、商品品质可信、门店拓客高效、履约链路清晰
- **业务模式：** 社区联营 + 线上下单 + 线下提货

## 用户角色

| 角色 | 主要诉求 | 核心能力 |
| --- | --- | --- |
| 消费者 | 快速找到附近门店并放心购买 | 定位找店、商品浏览、下单支付、到店自提、订单查询 |
| 联营门店店主 | 获取社区客源并提高成交与复购 | 商品管理、订单核销、库存管理、社区拼团、经营数据 |
| 平台运营人员 | 统一管理商品、门店和营销活动 | 门店审核、商品与内容管理、订单管理、营销配置、数据分析 |

## 核心业务流程

1. 用户授权定位，系统推荐附近营业门店。
2. 用户选择门店，查看该门店可售商品与预计取货时间。
3. 用户将商品加入购物车，提交订单并完成支付。
4. 门店接单备货，订单状态更新为“待取货”。
5. 用户到店出示取货码，门店核销并完成订单。
6. 用户可评价商品与服务，平台沉淀复购和运营数据。

## 功能规划

### 一、消费者端（当前优先）

#### 1. 首页

- LBS 自动定位并推荐附近门店
- 展示门店距离、营业状态和预计取货时间
- 轮播 Banner、活动入口和商品分类导航
- 展示“附近门店，15 分钟可取”的一刻钟生活圈信息
- 推荐热销、新品、拼团和复购商品

#### 2. 门店选择

- 地图或列表查看附近门店
- 按距离、营业状态等条件筛选
- 查看门店地址、营业时间、联系电话和自提说明
- 支持手动切换当前购物门店

#### 3. 商品与内容

- 商品分类、搜索、筛选和详情展示
- 展示规格、价格、库存、图文和视频内容
- 通过“黑米姐姐技术展示”科普技术原理与品质优势
- 收藏商品、加入购物车和分享商品
- 增强阶段展示商品从仓储到门店的物流轨迹

#### 4. 购物车与结算

- 调整商品规格与数量
- 校验门店库存、起售条件和商品状态
- 使用优惠券或参与营销活动
- 确认自提门店、预留信息和预计取货时间
- 提交订单并完成支付

#### 5. 订单与自提

- 查看待付款、待备货、待取货、已完成和售后订单
- 展示订单进度、取货码和门店导航
- 支持取消订单、申请退款和确认取货
- 订单完成后进行商品与门店评价

#### 6. 个人中心

- 微信授权登录与个人资料管理
- 常用自提人和联系方式管理
- 优惠券、积分、收藏和浏览记录
- 客服、反馈、隐私政策与用户协议

### 二、门店端（后续建设）

- 门店资料与营业状态管理
- 商品、价格和门店库存管理
- 接单、备货、取货码核销与售后处理
- 发起社区拼团并查看活动进度
- 查看销售、订单、商品和用户复购数据

### 三、平台管理端（后续建设）

- 用户、门店和权限管理
- 商品、分类、库存和内容管理
- 订单、退款、结算和售后管理
- Banner、优惠券、拼团等营销活动配置
- 物流轨迹、运营数据和风险监控

## 差异化能力

1. **黑米姐姐技术展示：** 在商品详情页通过视频和图文解释技术原理，建立品质信任。
2. **一刻钟生活圈：** 突出附近门店、实时营业状态和预计取货时间，降低用户决策成本。
3. **社区联营：** 让门店参与社区运营，并通过拼团、分享等方式持续拓客。
4. **物流可视化：** 在增强版本中展示商品从仓储到门店的流转轨迹，提高履约透明度。

## MVP 范围

首个可用版本聚焦“用户能完成一次到店自提订单”的最短闭环：

- 微信登录与用户授权
- 定位、附近门店与门店切换
- 商品分类、商品详情与购物车
- 提交订单、支付与订单状态查询
- 门店备货、取货码展示与核销
- 基础退款、客服和消息通知

社区拼团、积分会员、物流轨迹和精细化数据分析在基础交易闭环稳定后逐步上线。

## 非功能要求

- **易用性：** 核心下单流程操作简单，重要状态与按钮清晰可见。
- **性能：** 首页、门店和商品列表优先加载核心内容，图片按需加载。
- **可靠性：** 订单、支付、退款与库存变更需保证状态一致，关键操作可追踪。
- **安全性：** 遵循最小权限原则，保护用户身份、联系方式、支付和订单数据。
- **兼容性：** 适配主流手机尺寸与微信版本，并兼顾弱网环境。
- **合规性：** 明示定位、手机号等信息的使用目的，提供隐私政策与授权管理。

## 开发说明

项目尚处于初始化阶段，技术选型、目录结构、接口规范和部署方式将在消费者端方案确定后补充。开发过程中建议遵循以下原则：

- 先完成交易闭环，再扩展营销与数据能力。
- 订单、库存、支付和退款采用明确的状态流转规则。
- 门店相关商品、库存和订单数据必须按门店隔离。
- 用户切换门店时重新校验购物车商品、价格和库存。
- 所有关键业务操作保留日志，便于排查与审计。
